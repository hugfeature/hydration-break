# 隐私说明
休息与运动离线运行，无账号、服务器、广告、分析 SDK 或自动上传。
Android 在应用私有存储中保存提醒开关、间隔、时段、动作选择和最近一次触发记录；卸载会删除这些数据。本版关闭 Android 系统自动备份。
Windows 在当前用户 LocalAppData/RestAndMove 保存设置和最近的提醒状态；安装升级保留设置，卸载默认保留，可手动删除该目录。
通知由操作系统展示，可能在锁屏显示动作与提醒内容，可在系统设置中关闭锁屏显示。
Android 只申请通知、开机恢复和用户授权的精确闹钟权限。Windows 不需要管理员权限，不默认开机启动，不唤醒睡眠电脑。
应用不是医疗器械或个体化康复方案；动作不适时停止。
