# 休息与运动：分发计划
授权范围：Android 可下载正式版 + Windows 独立应用；离线、无账号、无服务器；不做浏览器扩展。
## 验收
- Android：保留 0.1.5 精确闹钟逻辑；诊断不占首页；动作可选且通知尊重选择；固定原签名、release 非 debuggable；覆盖升级保留设置。
- Windows：托盘独立运行；喝水/运动独立开关与间隔；时段、暂停；窗口关闭不退出；显式退出停止；睡眠不唤醒、恢复只重排不补发风暴。
- 分发：APK、Windows x64 自包含安装包和便携包，校验和、隐私与使用说明；不擅自公开私有仓库，不购买签名证书。
## 顺序
1. Android 界面和动作库，release 构建与升级测试。
2. Windows 原生 WinForms/.NET LTS 托盘应用，调度与持久化、安装/升级/卸载测试。
3. 下载交付及验证记录；将 CI、桌面 UI、真机实测分别报告。
## 验证边界
Android 真机曾报告 0.1.5 提醒可用；2026-10-11 又反馈普通提醒延迟超过三小时，截图显示精确提醒未授权。该问题暂缓处理，不能据此宣布真机可靠性验收通过。0.2.0 仍需真机回归。

正式分发构建不意味着应用商店审核或 Windows 可信发布者签名。
