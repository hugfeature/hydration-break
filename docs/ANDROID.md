# Android 安装与使用
安装 rest-and-move-0.2.0.apk。Android 8 及以上；Android 15 模拟器为自动验证目标。
0.1.4/0.1.5 已固定签名版可直接覆盖安装；更早随机签名版可能需要一次卸载。
首次打开允许通知；点击“开启精确提醒”，在系统页授权。锁屏通知仍需在系统设置中允许。
喝水和运动独立开关、独立间隔；每日时段点击保存。选择动作后点保存，可全部取消而保留一般活动提醒。
测试按钮和最近触发记录在“设置与帮助 → 提醒诊断”，首页不显示。
省电/厂商后台限制可能影响提醒；勿把测试通知成功等同于长期锁屏送达。连续两到三个周期、修改设置、重启后请在目标手机复核。
release 包非 debuggable；无网络权限、无自动备份、无账号。
