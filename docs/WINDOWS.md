# Windows 使用说明
首版目标：Windows 11 x64；Windows 10 未单独验证，ARM64 未验证。
安装 setup.exe，或解压 portable.zip 并运行 RestAndMove.exe；无需单独安装 .NET。
没有购买 Windows 发布者签名证书，系统可能显示未知发布者/SmartScreen 提示。不要关闭安全软件；不信任来源时不要运行。
打开后设置喝水/运动间隔、时段和动作，点击保存。双击托盘图标重新打开；关闭窗口仅隐藏，托盘“退出”才停止提醒。
默认不随开机启动，重启电脑后需手动启动。睡眠时不提醒、不唤醒电脑，恢复后重新计时，不批量补发。
Windows 勿扰和锁屏通知设置会影响可见性。请在设置与帮助里检查通知设置，并在自己电脑上验证锁屏送达。
设置保存在 %LOCALAPPDATA%/RestAndMove/settings.json。升级保留；卸载默认保留，需清理时手动删除该目录。
