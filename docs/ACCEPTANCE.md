# 目标设备验收（不等同于 CI）
## Android 0.2.0
1. 从已固定签名的 0.1.5 直接安装，检查开关、间隔和时段保留。
2. 授予通知及精确提醒，设置时段涵盖现在；喝水 15 分钟、运动 30 分钟，记录首页计划时间后锁屏。
3. 连续观察至少 3 个喝水周期、2 个运动周期，期间不要靠打开应用触发。验收：每次延迟小于对应周期，且锁屏期间已有通知。
4. 修改喝水间隔，运动计划不应被重置；关闭一个提醒，另一个继续。
5. 重启并解锁一次，再锁屏，检查提醒恢复。系统“强行停止”属于需手动启动的边界。
6. 仅选择一个动作，运动通知应只使用该动作；全部取消时只发一般活动提醒。
7. 出问题时进入“设置与帮助 → 提醒诊断”，记录计划、实际触发、延迟和通知结果。
## Windows 0.2.0
1. 安装并启动，设置提醒和动作，保存；关闭窗口，确认托盘图标仍在。
2. 在系统允许通知、关闭勿扰的条件下，分别检查工作中和锁屏时的正式提醒。CI 尚未验证目标 Windows 11 锁屏通知可见性。
3. 暂停 30 分钟后不通知；点击恢复后重新计时。
4. 睡眠后唤醒，不应集中补发；下一次按间隔重新安排。
5. 托盘退出应停止提醒；再次启动保留配置。首版不默认开机启动。
6. 重装保留设置；卸载删除程序但默认保留本地设置。未来版本之间的升级需在有下一版时追加验证。
