# 喝水与休息 / Hydration Break

离线 Android 健康提醒 App。无需 ChatGPT、登录、网络或后台常驻服务。

## 功能
- 喝水、活动提醒独立开关与间隔（15/30/45/60/90/120 分钟）
- 每天的提醒时段（默认 09:00–18:00）
- 系统通知提醒；开机、应用升级、设备时间变更后恢复调度
- 设置存储在手机本地

## 下载与安装
1. 打开仓库的 **Actions → Build Android APK**，选择最新成功运行。
2. 下载 `hydration-break-debug-apk` 构建产物并解压得到 APK。
3. 手机允许安装所下载的 APK；首次打开请允许通知权限。
4. 如提醒被系统延迟，可在手机系统的电池管理中允许本 App 后台运行。

## 构建
JDK 17 + Android SDK 35 + Gradle 8.10.2，执行 `gradle assembleDebug`。
GitHub Actions 自动构建调试版 APK；该 APK 并非正式签名发布版。

## 已知边界
- 使用非精确系统闹钟，Android Doze/厂商省电策略可能延迟提醒，**不保证分钟级准时**。
- 间隔是相对上次触发（或修改设置）计算；重新打开应用保留尚未到期的计划；跨越结束时间后下次从开始时间调度。
- 目前按每天同一时段运行，暂不支持按星期配置、跨午夜时段及喝水量统计。
- 只有成功授予通知权限、应用通知与“健康提醒”通知类别未关闭时才会显示提醒。
- 系统“强行停止”后需手动重新打开应用恢复；重启后的恢复在用户解锁后进行。
- 不申请精确闹钟、忽略电池优化或后台常驻权限。锁屏可见性、声音及厂商限制需在目标手机验证。
- 调试签名由 CI 环境生成，不承诺不同构建能覆盖安装；如签名不同，卸载重装会丢失本地设置。稳定发布签名需要单独配置。

## 本轮修复与验证范围（0.1.1）
- 首次启动即调度默认提醒；再次启动保留未来到期时间。
- 时段先校验后整体保存，无效输入不会取消已有提醒；独立开关、间隔立即生效。
- 显示通知/通知类别关闭状态，提供系统通知设置入口；处理通知权限撤销与闹钟权限异常。
- CI 增加计算边界单测、Android 15 仪器测试、APK 签名校验与实际安装/启动检查。
- 模拟器脚本检查后台、锁屏/Doze 下闹钟仍注册，以及实际重启后的重新注册和通知权限状态。
- 接收器通知测试是直接调用接收器，**不代表定时投递通过**；Doze 注册检查也不代表通知按时送达。
- CI 的真实结果以该提交 Actions 日志及 validation-reports 为准；失败步骤不能视为通过。
